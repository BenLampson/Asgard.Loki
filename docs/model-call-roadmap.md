Updated: 2026-10-20. **This is the only active coverage/delivery table.** The [archived history](archive/model-call-roadmap-history.md) is evidence, not an execution queue. Reference is fixed at New API `058c8231b68c51ee02abee15befcd720fee9f4a2`. The full non-truncated tree has 3071 entries; 195 relevant channel/plugin/dispatcher/handler files were downloaded read-only and verified against their Git blob SHA. Eleven task plugins and all channel adaptor implementations were inspected together with actual dispatch/response paths. No GitHub writes/workflows were performed.

Scope: **LLM, Audio, Video, Image, Embedding, Rerank**, including every actually implemented native model-call supplier/operation in that version. The user explicitly expanded supplier coverage beyond the first Volcengine implementation. Compatibility reuse is required where wire semantics match; a model catalog, endpoint string, interface, stub, panic or gateway route alone is not an implementation. `ConvertClaudeRequest` may translate to Chat and does not prove a native Claude endpoint. Current SDK features beyond this pinned minimum remain supported without adding more supplier-latest features to the queue.

Current verified checkpoint: **6943 passing offline tests**, 28 packages; original JSON/fields, tool IDs and native terminal semantics remain under regression coverage. `Delivered` is offline SDK support, not live model acceptance. `Reuse pending` means shared SDK transport/protocol exists but the concrete supplier profile/wire contract still needs verification; it is **not** counted as delivered. `Missing` requires native code. Rows group only the listed concrete operations, not every possible model dialect.
