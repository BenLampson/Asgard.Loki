# Asgard.Loki.Rerank.Ali.Tests

Offline xUnit v3 acceptance tests for the native DashScope nested rerank SDK provider. Six independent [wire fixtures](Fixtures/native.json) cover default text, top-n/document return/instructions, an oversized result limit, mixed text/image/video candidates, image queries and original document echo containers. Expected requests/responses are hand-maintained rather than generated by the production adapter.

The tests verify final endpoint/auth/model/native JSON, output array order and source indices, explicit document associations, missing/null return fields, exact integer/score boundaries, native usage, unknown fields, errors, malformed/duplicate/truncated JSON, stream headers, request/body cancellation, snapshots and borrowed resource ownership. Media echoes include a documented text wrapper matched using the original request context and explicit native modality objects; live server/media behavior is not inferred from these fixtures.

All HTTP is substituted. No credentials are read, models called, media downloaded, real workspace accessed or external Redis contacted. Passing protocol tests does not establish relevance, cross-request score comparability, media validity or account permissions. See the [provider initialization, support matrix and limitations](../../src/Asgard.Loki.Rerank.Ali/README.md).
