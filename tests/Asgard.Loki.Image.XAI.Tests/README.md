# xAI Image edit native vectors

Independent native JSON edit/request/result vectors sourced from the primary [single image guide](https://docs.x.ai/developers/model-capabilities/images/editing), [multiple image guide](https://docs.x.ai/developers/model-capabilities/images/multi-image-editing) and [Images REST reference](https://docs.x.ai/developers/rest-api-reference/inference/images). These expected values are not generated by adapter code. Targets, media URLs, file identifiers and credentials are fictional.

Preserves original image.url or ordered images[].url/file_id references, optional type and extensions, signed URL spelling, opaque IDs, inline data URI, n/response_format/aspect_ratio, unknown false/null/zero/exact integers, full data[] MIME/revision/usage and original errors. File IDs are model inputs only; no file-management API, upload, media fetch, stream or background task is exercised. These are protocol tests, not real xAI/model/entitlement or pixel-quality verification.
