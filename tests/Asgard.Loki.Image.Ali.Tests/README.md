# Ali Image protocol vectors

Independent offline native vectors, authored using the primary [Wan image API](https://www.alibabacloud.com/help/en/model-studio/wan-image-generation-api-reference) / [text-to-image API](https://www.alibabacloud.com/help/en/model-studio/text-to-image-v2-api-reference). They are not generated by the adapter or captured from a live account.

The four native POST paths and task GET are distinct operations. SSE vectors deliberately include intermediate `finished:true`, noncontiguous choice indices, text-only completion and cumulative usage. JSON includes modern messages, legacy prompt/base-image inputs, task-local failures, signed URLs, unknown fields and integers above 2^53. Credentials and example.invalid URLs are fictional; tests never download media or contact a supplier.
