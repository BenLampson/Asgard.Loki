# Asgard.Loki.Video.Tests

Offline public SDK tests cover independent Ark fixtures, original JSON snapshots, complete-target task-reference persistence/reconstruction, configuration drift, removed targets, wrong task IDs, no failover and borrowed adapter ownership. Optional raw HTTP windows preserve byte ownership and distinguish an exactly empty HTTP 202 running response from original JSON. Existing JSON snapshots and explicitly absent-JSON snapshots round-trip without inventing native fields; invalid absence/state/body combinations fail.

xUnit v3 / Microsoft.Testing.Platform. No real credentials, network, timers or Redis. Protocol fixtures do not establish actual model acceptance. Supplier transport/signature tests belong to their corresponding provider projects.
