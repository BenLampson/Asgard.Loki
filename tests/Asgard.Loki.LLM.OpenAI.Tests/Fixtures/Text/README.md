# Native compatible text windows

The caller, complete wire/result and separately embedded event list/raw SSE are independently authored. They describe the configured native text protocol, not a recorded provider execution or real account/model verification. Prompt/FIM tags, suffix/echo/logprobs, exact integers and unknown/empty/null/false values stay original. Sparse multi-choice/logprobs/unknown-field variants are generic transport fidelity cases; they do not assert DashScope accepts those shapes or settings. Current DashScope Completions supports string prompt/FIM tags and reports null logprobs; current DeepSeek FIM documents optional suffix/logprobs and actual SSE DONE. Supplier-specific restrictions remain caller-owned.

Sources: [DashScope Completions](https://docs.modelstudio.console.alibabacloud.com/en/model-studio/completions), [DeepSeek FIM](https://api-docs.deepseek.com/api/create-completion/). There is no retired OpenAI model catalog or claim of OpenAI legacy Completions availability. The unknown response.failed business event is deliberately distinct from Responses protocol state.
