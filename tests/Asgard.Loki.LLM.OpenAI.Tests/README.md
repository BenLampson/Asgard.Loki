# Asgard.Loki.LLM.OpenAI.Tests

Native compaction tests cover `/responses/compact` through the public SDK: full input/output windows, encrypted and retained items, unknown data, optional previous-response ownership, explicit target features, complete target binding, concurrent/stale first-binding decisions, cancellation, invalid results and no-retry HTTP errors. Test coordination uses `MemoryDistributedCache`; HTTP is replaced locally. Compaction result IDs are not registered as generation response IDs. No live OpenAI request or entitlement check is performed.

93 offline tests for the actual OpenAI LLM adapter: HTTP/JSON, fragmented SSE and a shared parameter matrix through the public Loki client. Final HTTP assertions cover native tool/reasoning items, schema parameters, unknown fields, false/zero/null, request immutability, route/model mapping and reserved-field rejection.

Six direct anonymous-credential boundary cases bring the complete OpenAI suite to 205 tests. HTTP/SSE Chat/Responses, compaction and WebSocket all fail before send/handshake when a caller bypasses routing with an anonymous credential; HTTP and sockets use substitute factories. This adds no anonymous OpenAI transport or live authentication claim.

xUnit v3 / Microsoft.Testing.Platform with stub HTTP and `MemoryDistributedCache`. Tests use no real provider credentials or external services. OpenAI has not been live-verified; wire preservation does not prove model behavior. See [verification scope](../../docs/llm-parameter-verification.md).

Current supplier total: **275 passing offline cases**. The HTTP checkpoint adds 64 cases and two independently authored full native fixtures, `Fixtures/chat-http.json` and `Fixtures/responses-http.json`. Their literal requests, complete responses, SSE wire and frame manifests are not captured from SDK output. Public SDK snapshots compare every native field and event/id/retry, preserving tool IDs/fragments, sparse indices, reasoning/encrypted items, strict schema parameters, false/zero/null and raw large integers. Historical counts above describe earlier milestones.

Transport regression tests check raw byte/declared lengths, strict UTF-8/duplicate JSON/invalid escapes, native identity/status and closure, DONE tail reads, late read/body/client disposal/final cancellation, failure/incomplete preservation, bounded terminal tails, early-exit cleanup and original native errors. Session cases prove unchanged full-target recovery across clients and policy/client mismatch before HTTP. Default constructor signatures remain available; new HTTP binding semantics deliberately invalidate predecessor OpenAI Sessions. The transport does not validate every choice/tool lifecycle or aggregate tool arguments. Everything uses fake HTTP, one-byte streams and `MemoryDistributedCache`; no real credentials or network.
