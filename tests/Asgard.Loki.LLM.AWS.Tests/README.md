# AWS LLM offline tests

xUnit v3 tests exercise native Bedrock Claude, Converse and Nova JSON/EventStream, Mantle Messages, explicit Runtime API Key/Bearer authentication, borrowed external principals and SigV4. All HTTP handlers, accounts, resources and credentials are fixtures; no AWS account, network or Redis is used. Published AWS example keys and fixture tokens are non-secret test data.

`request.json`, `wire.json` and `response.json` independently declare complete Claude requests and results, including original tool/result IDs, thinking/signatures/redaction, schema/beta/cache and exact unknown fields. `signatures.json` declares final paths, canonical paths, payload hashes and Authorization values for plain models/ARNs, direct/public SDK calls and static/temporary credentials. Python standard-library JSON/hash/HMAC/URL tools compute expectations from hand-authored wire bodies, without running production providers. The separate published AWS IAM ListUsers canonical request and signature exercise key derivation against an external standard vector.

`stream-events.json`, binary `native.eventstream` and `stream-frames.json` independently declare full typed headers, payload bytes, offsets and lengths. `stream-signatures.json` covers final signed HTTP requests. The binary fixtures must not undergo text or newline conversion. Direct framing tests isolate CRC/prelude/length/header failures from native Claude lifecycle failures; CRC-valid negative streams isolate orphan/mismatched tools/blocks, native errors and missing/repeated/reopened terminals. Unknown outer JSON and unsupported raw payloads retain their original frames.

Converse fixtures independently declare complete requests, results, signatures and native EventStream transcripts. Assertions cover media/cache/tool/result/reasoning/signature/schema fields, sparse indices, exact counters, explicit prompt-ARN requests without injected messages/defaults, native transport names, citations and unknown tails. `converse.eventstream` and its frame/signature manifests verify actual binary delivery separately from logical fake events.

`api-key-wire.json` verifies explicit Bearer/Host selection for Claude and Converse JSON/EventStream, absent SigV4/date/hash/token headers, original native payloads and default-header isolation. Mantle fixtures separately verify application-selected Messages resources, logical native streaming and borrowed credential sources; they do not infer Runtime endpoints or execute native tools.

Nova request/response and signature fixtures retain explicit v1/v2 envelopes, direct/nested settings, native tool/reasoning/opaque content, stop/usage/metrics and exact unknown values. Nova binary fixtures and separate envelope/header/frame manifests verify the native Base64 event wrappers, typed headers, interleaved tool fragments and held terminal delivery. Invalid indices, ambiguous envelopes, missing metadata, corrupt/truncated tails and protocol isolation retain separate negative regressions.

Shared [Nova/Converse fixtures](../Shared/Fixtures/README.md) verify optional explicit Conversion composition over real native adapters. Full request/output/event goldens cover declared dialects/layouts, SigV4/Bearer, schema and tool correlation, original metadata, strict/consented losses and native binary attachment ownership. AWS production has no Conversion dependency; target logical conversions never fabricate binary frames.

Resource and Session regressions cover credential/source/principal/configuration drift, stable-principal token rotation, secret-free identities, complete-target recovery, snapshots before asynchronous acquisition, caller-owned factories/sources, pre-cancellation, actual byte/length/JSON/UTF-8 limits, async-only/sync/client disposal, early exit and late failures withholding success. Real authentication, model entitlement, option effects, generated quality and remote/platform CI are not established by these offline tests.
