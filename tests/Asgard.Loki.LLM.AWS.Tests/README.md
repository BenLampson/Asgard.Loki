# AWS LLM offline tests

91 xUnit v3 cases exercise native Bedrock Claude InvokeModel JSON, External principal binding and SigV4 without an AWS account, real credentials, network or Redis. Published AWS example keys and fixture tokens are non-secret test data.

`request.json`, `wire.json` and `response.json` are independently authored complete native samples covering tool call/result IDs, error results, thinking/signatures/redaction, schema/beta/cache and exact unknown values. `signatures.json` has eight independent expected final paths, canonical paths, payload hashes and Authorization values: direct/public SDK, plain model/ARN and static/temporary credentials. Python standard-library `json`, `hashlib`, `hmac` and `urllib.parse` calculated them from the authored wire body; no production provider was run. Public DTO body ordering is independently declared as messages, max_tokens, then native extension fields. Expected values intentionally change with actual serialization bytes, without treating JSON property order as a semantic model requirement.

The separate published AWS IAM ListUsers canonical request and `5d672d79...` signature verify key derivation and final authorization against an external standard vector. Final HTTP tests verify the actual signed bytes, single escaping on the wire, non-S3 double canonical encoding, host/date, optional Session Token and native header whitespace normalization. Source-await snapshots, mutable option collection snapshots, refreshed credentials/fixed-target Session recovery and changed principal/configuration are explicit regressions. Credentials stay absent from default display/JSON and Session storage.

Substitute HTTP streams fragment every byte and inject EOF, read/disposal/cancellation faults. Native errors, strict raw-byte/Content-Length/JSON/encoding, default-auth isolation and unsupported streaming have separate tests. Explicit Chat-to-Claude text integration checks the full final body through the public SDK; the production package has no Conversion dependency. Complete JSON tests do not establish native EventStream or Converse support. Actual AWS authentication, model support/quality and two-platform CI are not claimed by this local suite.
