# AWS LLM offline tests

229 xUnit v3 cases exercise native Bedrock Claude InvokeModel JSON, External principal binding and SigV4 without an AWS account, real credentials, network or Redis. Published AWS example keys and fixture tokens are non-secret test data.

`request.json`, `wire.json` and `response.json` are independently authored complete native samples covering tool call/result IDs, error results, thinking/signatures/redaction, schema/beta/cache and exact unknown values. `signatures.json` has eight independent expected final paths, canonical paths, payload hashes and Authorization values: direct/public SDK, plain model/ARN and static/temporary credentials. Python standard-library `json`, `hashlib`, `hmac` and `urllib.parse` calculated them from the authored wire body; no production provider was run. Public DTO body ordering is independently declared as messages, max_tokens, then native extension fields. Expected values intentionally change with actual serialization bytes, without treating JSON property order as a semantic model requirement.

The separate published AWS IAM ListUsers canonical request and `5d672d79...` signature verify key derivation and final authorization against an external standard vector. Final HTTP tests verify the actual signed bytes, single escaping on the wire, non-S3 double canonical encoding, host/date, optional Session Token and native header whitespace normalization. Source-await snapshots, mutable option collection snapshots, refreshed credentials/fixed-target Session recovery and changed principal/configuration are explicit regressions. Credentials stay absent from default display/JSON and Session storage.

Substitute HTTP streams fragment every byte and inject EOF, read/disposal/cancellation faults. Native errors, strict raw-byte/Content-Length/JSON/encoding, default-auth isolation and pre-cancelled stream acquisition have separate tests. Explicit Chat-to-Claude text integration checks the full final body through the public SDK; the production package has no Conversion dependency. Complete JSON tests do not establish stream support; the independent binary suite below verifies EventStream. ConverseStream remains pending. Actual AWS authentication, model support/quality and two-platform CI are not claimed by this local suite.

The 97 additional EventStream cases have independent authored `stream-events.json` plus Python struct/zlib encoded `native.eventstream` and `stream-frames.json` containing full typed headers, payload bytes, offsets and lengths. The binary fixture is Git-binary and must never undergo text/newline conversion. Eight `stream-signatures.json` vectors independently declare actual HTTP path/body/hash/auth for direct/public SDK, model/ARN and static/temporary credentials. All ten header types, outer unknown fields, original Claude JSON/indices/tools/signatures/metrics, incremental versus held terminals and frame-view immutability are checked.

CRC/length/header failures are tested directly against the reader so a later Claude lifecycle error cannot mask a missing CRC check. Separate CRC-valid combinations test block/tool association, native failures and missing/repeated/reopened/changed terminal state, exact numbers and limits. Late corrupt/truncated frames, reads/disposal/cancellation cannot release held success. Unknown outer JSON remains visible; unsupported non-JSON payloads retain the valid raw frame on their explicit failure. Cross-mode credential rotation/fixed-target Session recovery and explicit Chat-through-Claude streams check normal completion and EOF-failure rejection. The new AWS provider domain requires fresh predecessor JSON-only Sessions; other providers/core/conversion identities remain unchanged. No network/live account or remote CI was used.
Converse complete JSON adds 41 provider cases. Independent `converse-request`, `converse-wire` and `converse-response` fixtures preserve native media/cache/tool/result IDs/reasoning/signatures/schema/unknown data. Four independently calculated `converse-signatures` vectors verify eight public SDK/direct adapter calls with model/ARN and static/temporary credentials. Prompt-ARN-only input omits messages/defaults; explicit unknown stream/version/type fields are not processed by Claude policies. Snapshot timing, source/target recovery, changed configuration/protocol, no implicit converter advertisement, original HTTP/root errors and late read/byte/JSON/length/disposal/cancellation faults have regressions. ConverseStream explicitly fails before source/HTTP and remains pending. No field/quality or live-model acceptance is inferred from forwarding these samples.
