# Dify native chat protocol tests

Offline xUnit v3 tests through DifyChatClient with a substitute HTTP handler and byte-fragmented, fault-injected streams. No real app Key, network, Redis or model access is required. The fixed-service client needs no model Session/cache.

Blocking-response checks use independent complete native samples. Independent whole caller/wire/blocking samples retain native input types, optional omission/empty/null, original answer/usage/retrieval/reasoning/unknown fields, exact numbers and distinct ID domains. Cases cover explicit app profile, native pause without resume, snapshots before factory creation, invalid aliases/Unicode/duplicates/Undefined before dispatch, raw HTTP/HTTP200 errors, budgets/declared length, actual method/URI and borrowed-factory versus owned-resource lifetime. EOF/read/disposal/final-cancellation faults cannot return a successful result.

Run after Release build: `dotnet test --project tests/Asgard.Loki.LLM.Dify.Tests/Asgard.Loki.LLM.Dify.Tests.csproj -c Release --no-build`. These establish local SDK protocol behavior, not live app/model acceptance or answer quality. The public stream client also compares every original frame with the independently authored Chatbot/Agent/Chatflow JSON windows and literal SSE transcripts.

The complete executable passes127 offline cases. Native SSE checks cover separate message/task/event/thought/file/node/workflow/run/transport domains, whole original reasoning/tools/media/unknown fields, Agent final-answer repetition without aggregation, replacement and TTS tails, direct no-run Chatflow answers, workflow failure/pause and stopped-before-message_end order. Missing/duplicate/wrong-order/late/changed-identity/invalid-JSON frames, HTTP200 errors after terminals, strict framing/UTF-8/declared-length/raw-byte/tail budgets, EOF/disposal/target/final-cancellation failures cannot release a held terminal. These are SDK protocol checks, not live app/model or audio validation.
