# Spark native offline tests

115 xUnit v3 cases exercise independent native JSON windows and eight Python-standard-library HMAC vectors through the public SDK/provider. The separately transcribed JSON-message fixture is passed as literal bytes and fragmented into three-byte reads; all original response JSON is compared byte-for-text and structurally against the independent golden window. The JSONL file is fixture storage for separate WebSocket messages, not an NDJSON wire protocol.

Fake sockets and a manually controlled TimeProvider verify one request, all native text/plugin entries, stable sid, increasing non-contiguous seq, distinct text/global completion, explicit CloseOutput and normal acknowledgement before disposal and terminal publication. CloseAsync deliberately fails so tests cannot accidentally consume/discard unobserved messages. Tests inject early/mid-fragment/abnormal/missing/late close or data, errors, byte/event/fragment/tail limits, invalid UTF8/JSON, altered bodies, Key rotation, AppId/source/factory/config drift, expiry/cancellation/handshake/close/disposal failures and native error preservation. Memory cache uses an explicit test coordinator; it does not establish cross-instance locking.

After a serial Release build, run `dotnet test --project tests/Asgard.Loki.LLM.Xunfei.Tests/Asgard.Loki.LLM.Xunfei.Tests.csproj -c Release --no-build`. No real credentials, external socket, model or Redis is used. No live authentication, service acceptance, availability or model quality is claimed.
