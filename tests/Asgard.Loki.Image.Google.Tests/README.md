# Gemini Image native vectors

Independent offline full native request/results and SSE authored using the primary [Generate Content image guide](https://ai.google.dev/gemini-api/docs/generate-content/image-generation) / [native API reference](https://ai.google.dev/api/generate-content). They are not generated by provider code and do not claim live model validation.

Preserves conversation image inputs, signed reasoning/image parts, native safety blocks, usage, noncontiguous candidate indices, metadata after final candidates, large integers, false/null/zero and unknown extensions. No media download, SDK-generated finish event or estimated tokens. Imagen predict is excluded: the [official Imagen page](https://ai.google.dev/gemini-api/docs/imagen), verified 2026-10-20, says Imagen is shut down in the Gemini API. This does not imply Vertex Imagen is retired or imply support for another API.
