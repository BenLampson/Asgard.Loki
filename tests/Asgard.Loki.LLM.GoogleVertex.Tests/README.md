# Vertex offline protocol tests

Three complete-call JSON fixtures are authored independently of the provider/converter: caller input, final native wire body and complete upstream result. Tests compare entire trees, preserving tool associations, opaque signatures, media/file and cache references, generation/schema/thinking settings, safety/grounding/usage, unknown null/false values and exact integers. These are forwarding fixtures; they do not establish that a live Vertex model accepts every field, particularly Developer API function IDs.

190 xUnit v3 cases exercise public SDK and direct-adapter boundaries with substitute HTTP, deterministic time, borrowed token/factory ownership and `MemoryDistributedCache` with an explicit coordinator. Response bytes are fragmented and EOF/disposal/cancellation failures are injected. The suite does not require keys, a Google account, network or Redis. Independent raw SSE and complete JSON event-sequence goldens cover native thought signatures, tools/IDs, grounding, unknown objects, exact numbers and event identity/retry. Separate lifecycle tests cover original finish/block reasons, precise ProtoJSON integer/enum forms, sparse/default indices, missing/repeated/reopened candidates, identity changes, late errors, raw byte/length and tail/candidate bounds, early exit, cancellation and release failures. Complete JSON tests alone do not establish stream support. Explicit complete/streamed conversion integration covers a representable text subset only.

Claude has three additional independent complete JSON fixtures (`claude-request`, `claude-wire`, `claude-response`) retaining tools/error results, signatures/redacted thinking, output schema, cache blocks/usage and unknown exact values. Forty added cases cover rawPredict routing/body version, conflicts and header/resource rejection, unchanged default Gemini binding bytes, token-refresh Session affinity, changed protocol/principal/version, native transport faults and explicit common-text conversion. They do not establish live acceptance or Claude SSE support.
