# Vertex offline protocol tests

Three complete-call JSON fixtures are authored independently of the provider/converter: caller input, final native wire body and complete upstream result. Tests compare entire trees, preserving tool associations, opaque signatures, media/file and cache references, generation/schema/thinking settings, safety/grounding/usage, unknown null/false values and exact integers. These are forwarding fixtures; they do not establish that a live Vertex model accepts every field, particularly Developer API function IDs.

150 xUnit v3 cases exercise public SDK and direct-adapter boundaries with substitute HTTP, deterministic time, borrowed token/factory ownership and `MemoryDistributedCache` with an explicit coordinator. Response bytes are fragmented and EOF/disposal/cancellation failures are injected. The suite does not require keys, a Google account, network or Redis. Independent raw SSE and complete JSON event-sequence goldens cover native thought signatures, tools/IDs, grounding, unknown objects, exact numbers and event identity/retry. Separate lifecycle tests cover original finish/block reasons, precise ProtoJSON integer/enum forms, sparse/default indices, missing/repeated/reopened candidates, identity changes, late errors, raw byte/length and tail/candidate bounds, early exit, cancellation and release failures. Complete JSON tests alone do not establish stream support. Explicit complete/streamed conversion integration covers a representable text subset only.
