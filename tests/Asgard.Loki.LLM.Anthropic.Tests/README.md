# Asgard.Loki.LLM.Anthropic.Tests

Offline xUnit v3 tests exercise the actual Claude provider through the public SDK client. Shared native tests cover request-local headers and final URI/model/stream, unknown parameters and zero/false/null/empty JSON, images/tools/results, thinking signatures, unknown fragmented SSE, HTTP and native errors, cancellation, invalid fields, Session continuation and incomplete streams.

All HTTP uses substitute handlers. Cache tests use `MemoryDistributedCache` and an explicit test-only coordinator. Tests do not require keys, network or Redis and do not establish live Anthropic model/account acceptance. See [testing](../../docs/testing.md).

Current total: **126 passing offline cases** (104 new at this checkpoint). Three independently authored embedded manifests provide complete request, JSON response, original SSE wire and separate event/id/retry expectations. Twenty-four cases exercise standard/Runtime/Mantle roots through both direct adapter and public SDK paths, with explicit header modes and complete/stream calls. This verifies the configured wire; model/endpoint acceptance of any optional setting or Bearer mode is not inferred.

Regression matrices cover raw UTF-8/JSON/length/body bounds; original HTTP/native errors; sparse block/tool association, duplicate IDs, incompatible deltas and malformed indices; missing/repeated/reopened terminals; state limits; early exit and read/async-dispose/sync-dispose/client/final-cancel failures. Authentication defaults cannot leak an unselected Key/signature. Named client, version, static Key, mode and resource changes invalidate Sessions before HTTP; actual predecessor binding bytes are written to the cache for migration rejection. Same-policy cross-client recovery and old constructor reflection checks remain explicit.
