# Asgard.Loki.LLM.Anthropic.Tests

**167 passing offline xUnit v3 cases** exercise the actual provider through direct adapters and the public SDK. HTTP is replaced locally; Session tests use MemoryDistributedCache with the explicit test coordinator. There are no real Keys, provider/Redis requests or live model/setting claims. See [testing](../../docs/testing.md).

| Native contract | Cases / coverage |
| --- | --- |
| Standard Anthropic and Bedrock Runtime/Mantle Messages | 127 cases with independent complete native request/result/SSE/event manifests, selected Key/Bearer/version, native block/tool identity and transport/resource faults |
| Explicit Ark Coding Plan | 16 full-window coding/v1/messages cases, selected Bearer, tools/reversed results, signatures/schema/unknown values, message_stop and binding/late-failure gates |
| Explicit Ollama Messages | 9 full local/proxy/hosted-profile cases, explicit placeholder or hosted Bearer, complete original data, actual message_stop and root/key drift |
| Explicit DashScope Messages | 15 complete legacy/workspace/proxy profile cases over both auth modes and JSON/SSE, native schema/effort/thinking/cache/empty signatures and Session drift |

Whole-body and per-event comparisons preserve native tool IDs/input fragments/reversed results, image/document blocks, thinking/signatures/redacted data, structured settings, exact numbers and unknown/null/false/zero/empty values. Complete response model and selected-target metadata remain separate. Event names/IDs/retry hints remain original; there is no reconnect, argument assembly or tool execution. Fixtures are authored independently, not generated by provider output.

Native state tests reject duplicate/missing/incompatible block/tool associations, malformed indices, repeated/reopened/missing terminals and state-limit overflows. Full standard windows use content-array indices consistently; a separate raw sparse-int.MaxValue regression proves no indexed-array allocation and does not certify a complete Claude content array. The separate conversion suite keeps its stricter sparse-block rejection.

HTTP matrices check raw UTF-8/JSON/declared-length/body bounds, original native/HTTP errors, selected default-header isolation, early exit, late reads, async/sync/client disposal and final cancellation. message_delta.stop_reason, message_stop and unknown tails wait until normal EOF and owned-resource closure. Missing message_stop must fail specifically as native truncation, never success inferred from closed blocks or EOF.

Complete Session tests cover static Key/auth/version/client/policy/root/model changes, genuine predecessor identity rejection, delimiter collision prevention and same-configuration cross-instance recovery. Borrowed factories/cache/coordinators stay caller-owned. No model-prefix routing, host inference, login/source refresh, CLI/server/workspace management or production supplier-peer reference is introduced. Optional field passthrough and configured-profile tests do not establish live entitlement, model behavior, schema validity or parameter effectiveness.
