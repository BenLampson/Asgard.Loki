# Asgard.Loki.Audio.Cloudflare.Tests

Independent native audio fixtures use the official [Whisper binary input](https://developers.cloudflare.com/workers-ai/models/whisper/schema-input.json), [Whisper output](https://developers.cloudflare.com/workers-ai/models/whisper/schema-output.json), [Whisper Turbo JSON task input](https://developers.cloudflare.com/workers-ai/models/whisper-large-v3-turbo/schema-input.json), [Turbo output](https://developers.cloudflare.com/workers-ai/models/whisper-large-v3-turbo/schema-output.json) and [REST envelope](https://developers.cloudflare.com/workers-ai/get-started/rest-api/) contracts.

`Fixtures/cloudflare-audio.json` was authored independently of production code. Python wave/Base64 validates a five-sample fictional WAV and exact original bytes in the JSON carrier. Three requests distinguish raw-binary recognition from explicitly selected JSON/Base64 transcribe and translate tasks; a raw binary upload has no invented translation switch or discarded form fields. Full results retain words/segments, transcription metadata, WEBVTT, empty speech text, diagnostics, native error envelopes and unknown nested fields, with zero/false/null and exact large integers. Fixtures establish structure only, not real model/account acceptance or recognition/translation quality.
