# Asgard.Loki.Embedding.Jina.Tests

Offline xUnit v3 acceptance tests for the native Jina dense/per-token Embedding supplier. Eight independently authored [complete wire fixtures](Fixtures/native.json) cover scalar text, native media batches, fused content groups, Float/Base64 matrices, implicit per-token output, nullable settings and an explicit empty batch. Golden values are not generated by production code.

The 134 cases verify public SDK/native final HTTP requests/results, input-index and token-list association, group boundaries, nullable/false/unknown fields, exact numeric/counter semantics, source snapshots, empty native shapes, oneof/setting/format conflicts, explicit PDF/packed/sparse boundaries, malformed/duplicate/truncated JSON, HTTP/200 business errors, stream rejection, send/body cancellation and borrowed ownership.

All HTTP is substituted, including the endpoint configured for the public Jina API. No Key is read, real model called, file downloaded, PDF parsed, media decoded or external Redis used. Fixtures establish protocol handling, not live model support, tokenization accuracy, media validity, vector quality or packed/sparse/PDF association. See the [provider matrix and initialization](../../src/Asgard.Loki.Embedding.Jina/README.md).
