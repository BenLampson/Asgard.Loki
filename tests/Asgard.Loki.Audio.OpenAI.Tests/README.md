# OpenAI Speech offline protocol tests

Run the Release build of `Asgard.Loki.Audio.OpenAI.Tests.csproj`, then its xUnit v3 executable, or use the repository offline test script after building the solution. All 173 cases run against a local replacement HTTP handler (103 binary/request plus 70 SSE).

`Fixtures/native.json` and `convenience.json` are independent complete wire requests, not generated by provider code. `terminal.json` records the complete SDK HTTP metadata terminal; it is not an upstream SSE event. Assertions also verify the full byte stream, intermediate cumulative counts, exact header values, route/target identity and absence of fabricated native usage/events.

SpeechReadStream injects short/long/empty bodies, partial read faults, cancellation and asynchronous disposal failure. SpeechTestHttpClient independently observes client disposal. Malformed lengths, unexpected media types, raw HTTP/JSON/text errors and request snapshots are covered without real credentials or network access. The arbitrary byte samples include invalid UTF-8 and are intentionally not speech-quality or media-container validation.

`sse-request.json`, `sse-events.json` and `sse-terminal.json` are independent complete request/event/envelope samples for the declared delta/done shapes. Tests preserve raw data and unknown JSON, inherited/reset SSE identity, Base64 audio associations and native usage without recomputation. They reject missing/late/duplicate terminals, error events even after done, malformed UTF-8/JSON/Base64/usage, ambiguous duplicate members, truncated event tails and decoded-audio/HTTP-length confusion. Read, cancellation, early stop and disposal faults are checked through both direct adapters and the SDK core. Source provenance and the current rendered-reference limitation are recorded in the provider README; offline examples do not prove a live model's event behavior.
