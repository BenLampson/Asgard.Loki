# OpenAI Speech offline protocol tests

Run the Release build of `Asgard.Loki.Audio.OpenAI.Tests.csproj`, then its xUnit v3 executable, or use the repository offline test script after building the solution. All 103 cases run against a local replacement HTTP handler.

`Fixtures/native.json` and `convenience.json` are independent complete wire requests, not generated by provider code. `terminal.json` records the complete SDK HTTP metadata terminal; it is not an upstream SSE event. Assertions also verify the full byte stream, intermediate cumulative counts, exact header values, route/target identity and absence of fabricated native usage/events.

SpeechReadStream injects short/long/empty bodies, partial read faults, cancellation and asynchronous disposal failure. SpeechTestHttpClient independently observes client disposal. Malformed lengths, unexpected media types, raw HTTP/JSON/text errors and request snapshots are covered without real credentials or network access. The arbitrary byte samples include invalid UTF-8 and are intentionally not speech-quality or media-container validation.
