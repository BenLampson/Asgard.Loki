# Asgard.Loki.LLM.Google.Tests

Offline xUnit v3 tests exercise the actual Gemini Developer API provider through the public SDK client. Shared native tests check the versioned model/action URL, `x-goog-api-key`, native contents and opaque thought signatures, generation extensions, body omission of model/stream, fragmented SSE, unknown events, errors, cancellation, Session continuation and missing terminal events. Additional tests verify every observed candidate must finish and preserve blocked-prompt feedback without fabricating a candidate.

All HTTP uses substitute handlers; cache tests use `MemoryDistributedCache` and test-only coordination. No live Gemini account, model entitlement, network or Redis verification is performed. See [testing](../../docs/testing.md).

Terminal regressions cover repeated candidate finishes, data after errors or blocked prompts, and valid usage-only tails after candidate completion.

Independent upstream fixtures contain complete native/proxy JSON/SSE windows with original signatures, reverse tool results, media references, thinking/schema/unknown settings and raw usage. Regressions verify ending delivery after actual EOF and owned closure, candidate/response identity, strict UTF-8, binary HTTP errors, late read/disposal/final cancellation, sparse candidate/tail/byte budgets, complete Session drift/replay and rejection of unrelated credential defaults. Unknown metadata-only business type frames stay metadata rather than native errors; an added type field cannot hide an existing native candidates/usage/feedback carrier. HTTP and transport failures keep their original status/body; no fixture proves real model/settings/search/ciphertext acceptance.

Tests use a prior independent literal Gemini body/result/event/SSE window and separately authored model/auth path expectations. Five credential modes, dynamic escaped model paths and explicit fixed-model declarations are exercised through the public SDK. Assertions cover complete native unknown values/tools/reverse results/signatures/candidate identities, immutable input, selected Host/defaults, invalid config/kinds, exact old default binding format, static-model mismatch/binding drift, raw binary errors, missing/repeated/post-finish/late-error/block frames, typed known carriers, early exit and late EOF/final cancellation. No live server/model/setting/signature/ciphertext validation is claimed.
