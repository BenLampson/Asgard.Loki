# Azure offline protocol tests

Run the xUnit v3 executable after building this project in Release, or use the repository's ordinary offline test entry point. No network, credentials, Azure account or Redis is needed.

Seven complete-call JSON fixtures are authored independently of the provider and converter: caller Chat/Responses inputs, v1/dated final Chat wire bodies, final Responses wire body and both complete native results. Tests compare entire JSON trees, including unknown members, filters, encrypted reasoning, schema wrappers, original tool association IDs and exact large integers. Only deployment/stream/routing changes are intentional. Conversion integration separately uses a representable common-subset fixture; it does not claim conversion of every Azure-specific field.

Authentication tests use a mutable deterministic clock and borrowed token source. Lifecycle tests fragment response bytes, inject EOF/disposal failures and cancellations, and check client ownership. Session tests use `MemoryDistributedCache` and the explicit test coordinator. Token refresh is simulated; the suite is protocol verification, not live cloud authentication/model verification. Independent raw SSE fixtures and full JSON event goldens cover both protocols, unknown events, native tool associations, asynchronous filter/usage tails and SSE identity/retry metadata. Separate lifecycle/transport tests cover missing/repeated/late terminals, changed identity/status, total byte and tail/choice bounds, cancellation, malformed encoding and EOF/disposal failures. The suite currently has 155 cases; complete JSON tests alone are not used as evidence for streaming support.
