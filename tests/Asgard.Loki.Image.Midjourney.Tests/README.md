# Asgard.Loki.Image.Midjourney.Tests

Independent fictional protocol vectors cover the native image operations of an explicitly configured unofficial Midjourney proxy. They are authored before implementation and follow the [proxy API contract](https://github.com/novicezk/midjourney-proxy/blob/main/docs/api.md), the frozen [submit controller](https://github.com/trueai-org/midjourney-proxy/blob/b68b2baa6667fa14306e521205ff687f9e10d83f/src/Midjourney.API/Controllers/SubmitController.cs), [task controller](https://github.com/trueai-org/midjourney-proxy/blob/b68b2baa6667fa14306e521205ff687f9e10d83f/src/Midjourney.API/Controllers/TaskController.cs) and [face-swap controller](https://github.com/trueai-org/midjourney-proxy/blob/b68b2baa6667fa14306e521205ff687f9e10d83f/src/Midjourney.API/Controllers/InsightFaceController.cs).

The request samples retain original prompts/flags, native image inputs, one-based image selection, opaque button/parent identity, mask, callback/state and unknown fields. Submit task IDs, existing/queued acknowledgements, queue-full errors with a result ID, input-upload URL arrays, seed values versus queued seed requests, native task states and reordered task lists stay distinct. Descriptions/shortened text are not invented image outputs; progress 100% alone is not completion. There are no real credentials, accounts, Discord connections, live proxy calls, downloaded images or production-generated expected snapshots.

63 offline xUnit v3 cases now verify every retained operation, original native body/result snapshots, raw upload/seed responses, known/unknown/text-only task outcomes, persistent target binding, task lists associated by ID with native order, missing/mismatched/duplicate results, opaque ID escaping, changed response target and byte/length/encoding/cancellation/disposal failures. No network, accounts, keys, Redis, live model acceptance or media retrieval are used.
