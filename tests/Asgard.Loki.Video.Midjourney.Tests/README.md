# Asgard.Loki.Video.Midjourney.Tests

Independent offline wire/result fixtures for a caller-configured, unofficial Midjourney proxy video contract. These do not represent an official Midjourney-hosted API or prove live account/video availability. The SDK supplies no proxy server, Discord connection, account pool, callback receiver or background poller.

The protocol-only fixtures follow the proxy author's [video request DTO](https://github.com/trueai-org/midjourney-proxy/blob/b68b2baa6667fa14306e521205ff687f9e10d83f/src/Midjourney.Base/Dto/SubmitVideoDTO.cs), [submission response](https://github.com/trueai-org/midjourney-proxy/blob/b68b2baa6667fa14306e521205ff687f9e10d83f/src/Midjourney.Base/Models/SubmitResultVO.cs), [native task statuses](https://github.com/trueai-org/midjourney-proxy/blob/b68b2baa6667fa14306e521205ff687f9e10d83f/src/Midjourney.Base/Models/Enums.cs), [task/video result fields](https://github.com/trueai-org/midjourney-proxy/blob/b68b2baa6667fa14306e521205ff687f9e10d83f/src/Midjourney.Base/Models/TaskInfo.cs) and [native authentication description](https://github.com/novicezk/midjourney-proxy/blob/main/docs/config.md). Fixtures are independently authored original JSON, not copied implementation code.

Requests preserve original image/endImage, motion, loop, videoType, batchSize, state, notifyHook and extension action/taskId/index, including index zero. Native model/type is configured independently from the SDK public route. Unknown null/false/zero, nested members, large integers and signed links test preservation. Submit codes 1/21/22 retain their original meanings and data; failures 23/24 and missing tasks remain errors. Native status, progress, cancellation, all video URLs/thumbnails, legacy VIDEO imageUrl carrier and task identity are independent of HTTP success. All credentials, media, IDs and output links are fictional, and model-specific acceptance remains unverified.
