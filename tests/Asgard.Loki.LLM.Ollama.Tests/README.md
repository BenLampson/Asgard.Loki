# Ollama native Chat offline tests

97 xUnit v3 cases exercise public `.LLM.OllamaChat` calls and the provider's direct boundary using substitute HTTP handlers, byte-by-byte UTF-8 streams and `MemoryDistributedCache`. `Fixtures/request.json` and independently authored `wire.json` compare the complete final native request; `response.json` and `events.json` retain full native results and record order, including unknown JSON and tools with/without original IDs. Expected data is not generated by the production implementation.

The fixture messages include image references, thinking history, tool arguments with exact integers and ordered properties, and `tool_name`/`tool_call_id` replies. They demonstrate protocol retention, not image decoding, tool execution or deployed-model support. Complete request snapshots, explicit native reasoning/schema settings, full-target binding and anonymous/default-header isolation run through the public SDK. Transport tests separately exercise byte limits, Unicode, malformed/duplicate/late/truncated records, media, declared length, cancellation, HTTP/native errors and EOF/disposal ordering.

Run locally after restore/build:

```powershell
dotnet build tests/Asgard.Loki.LLM.Ollama.Tests/Asgard.Loki.LLM.Ollama.Tests.csproj -c Release --no-restore -warnaserror -m:1 -p:UseSharedCompilation=false
dotnet tests/Asgard.Loki.LLM.Ollama.Tests/bin/Release/net10.0/Asgard.Loki.LLM.Ollama.Tests.dll -noLogo -parallelMode none
```

No actual Ollama/cloud/model, live credentials, network or Redis is used. `/api/generate` and protocol conversion remain separate follow-up work. See the [provider contract and limitations](../../src/Asgard.Loki.LLM.Ollama/README.md).
