# OpenAI Image offline protocol tests

256 xUnit v3 cases: five existing generation JSON/SSE cases, 119 native nonstream image-editing cases and 132 editing SSE cases. Tests use the public SDK or the explicit adapter with local HTTP substitutes, fake credentials and `.invalid` domains. No network, actual image codec/rendering, real key, live model or mask-quality check is used.

`Fixtures/edit-json-input.json` is an authored native request. The independent complete `edit-json-wire.json` expected request changes only the bound actual model. Three complete MIME goldens cover multiple images/mask, multiple images without mask and a minimal single upload with omitted content type/defaults. The test-only MIME reader decodes actual serialized bytes into full ordered header/body entries and normalizes only the random boundary; it does not call production builders to create expected output. `edit-json-response.json` retains native Base64/URL items, revised prompt, usage, nested null/false and integers/decimals beyond common floating-point precision. Arbitrary upload/result bytes do not prove a valid image format.

Cases verify native JSON/file references, current stream positions, Unicode file names, separate first-image mask role, unknown/repeated/empty multipart fields, independent direct-entry snapshots, target headers, no downloads/fallback/retry and one-shot upload serialization. Negative cases cover ambiguous/reserved/duplicate inputs, invalid encoding/MIME, explicit stream=true refusal, native HTTP/business errors with exact raw bytes, malformed/duplicate result JSON, unexpected media and length/read/upload/disposal/cancellation failures. Response-content disposal, stream DisposeAsync and client disposal faults are tested independently. Borrowed upload streams and factories remain caller-owned.

Editing SSE has two additional complete JSON/MIME request goldens, a full native source SSE and independently authored expected event sequence. Cases compare all fields, exact native values and multiline raw JSON/SSE identity under byte-at-a-time and larger fragmentation. Unknown completed-looking events remain nonterminal; fewer/no partial images are allowed. Exact integer checks reject near-integer or negative underflow values without narrowing or huge exponent expansion. Native errors retain raw payload and event identity even after a held completed event.

SSE lifecycle tests cover malformed/truncated/duplicate/late/native-error tails, EOF and declared-length checks, stream/response/client disposal faults, cancellation from method or enumeration, early stop and invalid UTF-8. Success waits until all source/transport resources close. Snapshots survive caller document disposal/list mutation, non-enumeration causes no HTTP/uploads and repeated enumeration cannot replay. This does not establish actual multiple-output streaming, image encoding or visual behavior.

Build in Release, then run this project's xUnit executable or `eng/Test.ps1` after a full solution build. `Asgard.Loki.Image.Tests` separately validates core custom-adapter contracts. The five generation cases remain separate from editing SSE coverage. No GitHub Actions or live supplier call is required by this suite.
