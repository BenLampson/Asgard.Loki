# Cloudflare LLM offline contracts

Independent synthetic native ai/run text and account-scoped compatible Chat/Responses fixtures, independently authored. Literal caller, expected complete/stream wire, complete raw response and event windows are independent resources; the SSE transcripts are hand-written separately. They are not live captures, current model support claims or gateway translations.

The native profile preserves the full result/success/errors/messages envelope, body omission of route Model, native prompt/history, opaque tool arguments, exact numbers and unknown fields. Native SSE retains raw JSON or actual [DONE] control data and original event/id/retry. The compatible profile preserves tool association IDs, reversed tool results, sparse native choice/tool indices, reasoning/encrypted items, structured settings, options.rejectIfBusy and unknown fields. Only configured actual model and method-owned stream mode change for compatible calls.

References: [Workers AI compatibility](https://developers.cloudflare.com/workers-ai/configuration/open-ai-compatibility/), [native REST](https://developers.cloudflare.com/workers-ai/get-started/rest-api/), [run API](https://developers.cloudflare.com/api/resources/ai/methods/run/) and [native text SSE](https://blog.cloudflare.com/workers-ai-streaming/). Current Responses support is explicitly non-streaming and GPT-OSS only; no Responses SSE window is invented. Fixture namespaced text/chat model names are synthetic, not catalog entries. Different ai/run model dialects require an explicitly selected profile; no name guessing or automatic conversion is implied. Fine-tuning, gateway hosting and batch orchestration are outside this contract.

The compatible windows are executed separately by OpenAI.Tests: the existing OpenAI provider suite verifies their full protocol windows. Native ai/run fixtures are exercised by this independent supplier suite; compatible tests do not substitute for native protocol verification.

The native Cloudflare supplier executes tests through public SDK/direct adapter with fake HTTP, byte-fragmented streams and MemoryDistributedCache plus explicit test coordination. Whole independent native wire/envelope/SSE windows cover unchanged tool names/opaque arguments, exact values, model path namespaces and actual DONE identity. Boundary cases cover no body model injection, unsupported inputs/auth/defaults, URI/method/policy drift, snapshot before factory creation, strict JSON/UTF-8, byte/declared-length limits, early consumer exit and read/disposal/final-cancellation failures. DONE is held through actual EOF and owned resource closure; duplicate/late data and explicit errors after DONE cannot first release a terminal. HTTP/native error bytes/status/type remain accessible.

Core contract tests use independent in-memory adapters and are also separate. No actual Cloudflare Key/account/model, external network, Redis, native option acceptance or answer/tool quality has been verified.

After a local Release build, run `dotnet test --project tests/Asgard.Loki.LLM.Cloudflare.Tests/Asgard.Loki.LLM.Cloudflare.Tests.csproj -c Release --no-build`. Ordinary tests stay offline; no new live environment variables or integration entry are added.
