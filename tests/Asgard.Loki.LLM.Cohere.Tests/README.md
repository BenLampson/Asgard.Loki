# Asgard.Loki.LLM.Cohere.Tests

Independent synthetic native Cohere v1 protocol fixtures, authored before the adapter implementation. Request and expected wire are separate literal resources; expected event windows are separate from the LF-delimited transport transcript. These are offline contracts, not captured live responses or model acceptance evidence.

The full request covers every history turn, repeated tool names with distinct native call parameters/results, document IDs, false/zero/null, exact large integers and unknown nested fields. Responses retain separate response_id/generation_id, citations, search data, complete history, native usage and unknown fields. A minimal response deliberately omits optional IDs/finish_reason and retains valid empty tool-planning text. Stream windows cover current events without is_finished and legacy optional flags, interleaved native tool indices/parameter fragments, full stream-end and trailing unknown metadata. No OpenAI IDs, tool assembly, SSE metadata or DONE are expected.

Protocol sources: [v1 Chat](https://docs.cohere.com/v1/reference/chat), [v1 streaming](https://docs.cohere.com/v1/reference/chat-stream), and the official [Python native response/event/tool types](https://github.com/cohere-ai/cohere-python/tree/main/src/cohere/types). The v1 default stream is newline-delimited; its terminal is event_type=stream-end, not a mandatory legacy is_finished flag. Tool results associate a native call name plus parameter object with outputs; response_id is distinct from generation_id. The [deprecation table](https://docs.cohere.com/docs/deprecations) is checked separately from model-specific acceptance.
