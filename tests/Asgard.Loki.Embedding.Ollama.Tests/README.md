# Asgard.Loki.Embedding.Ollama.Tests

Offline xUnit v3 acceptance tests for the native Ollama `/api/embed` SDK provider. Six independent [wire fixtures](Fixtures/native.json) cover scalar text, text batches, image, audio, mixed media/text and explicit empty calls. The expected bodies and vectors are hand-maintained, not generated by the provider.

Public SDK cases compare complete request and response JSON, native endpoint/auth/model, exact optional counters, raw metadata, vector values/order and source immutability. Empty scalar versus empty batch entries retain distinct counts. Rejection cases cover malformed/native-incompatible input, settings, media encoding, returned counts/dimensions, nonfinite values, counters, duplicate/truncated JSON, errors and SSE/NDJSON. Lifecycle cases verify request/body cancellation, snapshot independence and borrowed HTTP ownership.

No tests read credentials, invoke a model, contact localhost/network/Redis, launch Ollama, download media or install a model. Successful protocol fixtures do not prove embedding quality, renderable media, server-side truncation or model-specific setting support. See the [provider support matrix](../../src/Asgard.Loki.Embedding.Ollama/README.md).
