# Asgard.Loki.LLM.Conversion.Tests

Offline xUnit v3 conversion acceptance tests use hand-maintained fixtures, not production converters to generate expected values.

- Twelve request directions check independent native field paths for instructions, text, Base64 images, function definitions, original call IDs, JSON parameters, result links, named choice and output limits.
- Twelve complete-response directions check actual text, original function IDs, arguments, finish/usage shape and source immutability.
- Twelve stream directions check text before completion, complete tool arguments, target lifecycle, item indices, sequence numbers, final snapshots and usage.
- Twenty-four complete/stream public SDK pipeline cases use the real OpenAI, Anthropic and Google adapters with substitute HTTP handlers and fragmented SSE, verifying final endpoint/authentication/model/stream and conversion metadata.
- Regression cases cover unknown fields, explicit loss consent, native copies, immutable snapshots, signed/encrypted state, response-chain rejection, schema/effort, tool choice none, orphan/ambiguous/parallel tool calls, truncated/failed streams, inconsistent final output, timestamp mapping and changed Session conversion identity.
- Usage cases verify Claude cache-read versus uncached input and Gemini candidate versus thinking output counts, as well as OpenAI detail/zero-value preservation.
- Complete OpenAI URL citations add 64 cases: two authored full reply goldens, source/range/order preservation, ASCII prefix rebasing, Unicode ambiguity, malformed/unknown fields, original JSON, tool association, history/stream boundaries and four public HTTP/SSE cases. That complete-response slice does not enable target stream mappings; native streams retain all citation events and snapshots.
- Responses source annotation integrity adds 68 cases: an authored two-part Unicode source and six-event consented-loss Chat golden, ten public SDK/fragmented-SSE cases, item/part/annotation identities, raw done/final snapshots, URL ranges, unknown/null data, late events, truncated terminals, state limits, immutability and Session binding. Explicit display-loss consent cannot bypass invalid native state. These checks do not add target citation deltas or validate live search quality.
- Gemini stream grounding source integrity adds 49 cases: an authored incremental full source, native request and independent consented-loss Chat sequence; global indices across frames, duplicate URLs, pending sources, structural ranges/containers, metadata-only tails, shared chunk/support resource limits, mutation and a cached old-algorithm Session rejection. Fifteen real-adapter/public SDK cases verify endpoint/auth/body, strict boundaries and no premature target terminal or retry. The source-integrity slice alone does not map segment-to-accumulated-text or target citation events; fixtures do not certify actual Google Search output or pending-reference ordering.
- Declared Gemini → Responses citation streams add 54 cases (1589 conversion at that checkpoint): independently authored full source/request/fifteen-event target and hand-calculated scalar/UTF-16/UTF-8 annotation lists; exact byte/part/source/text identity, repeated URLs/text, empty/overlapping ranges, immutable submitted source, expanded-output limits, unknown/null/false metadata and hard layout failures. Eighteen public SDK cases verify final native endpoint/auth/body, EOF/disposal before citations, invalid/truncated/late/blocked sources, read/dispose/cancellation failures, incomplete finishes, missing declarations before HTTP and cancellation between final events. An independent Responses source state machine validates the generated target lifecycle. Default/other pairs and native copies remain separate; no real search is called.
- Complete reverse OpenAI URL citations → Gemini Web grounding adds 51 cases: six source snapshots and two independent complete targets, exact declared Unicode units, original part indices across functions, duplicate/overlapping/empty ranges, six semantic roundtrips, nine public SDK/HTTP cases, strict/consented source losses, unknown fields and truncation/safety terminals. Stream finalization does not enable this mapper; native copies retain their contract. No real search is called.
- User PDF inputs add 126 cases, including twelve independent full request comparisons and history roundtrips, distinct file-byte/order checks and 42 public SDK HTTP/SSE cases. Rejections cover malformed/missing data, MIME inference, provider references, unresolved URLs, roles and conflicting sources. Filename/unknown metadata remain explicit losses; native copies preserve references. Opaque byte fixtures and ordinary text replies do not verify renderable documents or live file/model behavior.
- Explicit UTF-8 `text/plain` files add 100 cases (1689 conversion total): three complete authored native requests with two files and original tools, six directional goldens/replays, raw Unicode/Base64/byte boundaries, BOM/NUL/CRLF preservation, metadata/filename diagnostics, Chat/source/role/reference boundaries, rich-result association and Session invalidation. Thirty-four public SDK HTTP/SSE cases compare full native bodies/auth/paths and prove encoding/size/Chat/invalid-byte failures before HTTP. Files remain documents, not flattened text messages; no real supplier or document-understanding behavior is asserted.
- Rich tool-result history adds 120 cases: eight complete/roundtrip goldens and 40 public SDK HTTP/SSE cases, ordinary/custom/namespace identity, string/array distinctions, exact custom-array JSON byte bounds, raw Unicode, error/opaque/reference failures and parallel Chat turn ordering. Unsupported arrays are never stringified or wrapped to fake another native result shape. Tool execution and result-delta streams are outside these tests.

The tests use `MemoryDistributedCache` and explicit test coordination. They never read live credentials or contact models/Redis. Passing this suite establishes the [documented subset](../../src/Asgard.Loki.LLM.Conversion/README.md), not universal lossless conversion or model behavior.

Embedded [source and golden fixtures](Fixtures/README.md) add 36 complete structure/event comparisons across the twelve directions. Generation settings have separate twelve-direction effort/Schema assertions, 24 public SDK/HTTP settings cases, and rejection tests for budget/effort/output-intent conflicts, unsupported metadata/enforcement, zero/false/null handling, parallel switches and changed Session options. Original schema constraints and source envelopes remain independently asserted.
