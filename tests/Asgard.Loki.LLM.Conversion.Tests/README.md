# Asgard.Loki.LLM.Conversion.Tests

Offline xUnit v3 tests exercise the [documented explicit conversion subset](../../src/Asgard.Loki.LLM.Conversion/README.md). Expected values are hand-maintained [complete fixtures](Fixtures/README.md), not production converter output. Tests use MemoryDistributedCache, explicit coordination, substitute HTTP handlers and fragmented native streams; no live credentials, models or Redis are accessed.

Request, complete-response and stream matrices cover declared Chat/Responses/Claude/Gemini directions, instructions, native fields, Base64 image references, reasoning settings, JSON Schema constraints, function/custom definitions, explicit tool choices, original IDs/arguments/results, finish/usage shapes and complete final snapshots. Native copies preserve original unknown/signed/encrypted data. Unsupported mappings require explicit failures; display-loss consent cannot bypass malformed native state or broken associations.

Tool-history regressions retain reversed parallel and same-name associations, string/array distinctions, rich text/image/PDF results, namespace/custom identity, exact argument numbers, failure flags and caller-declared Gemini error formats. Orphan, duplicate, ambiguous or mismatched IDs, incomplete arguments and inconsistent final snapshots remain negative cases. Tools are never executed by these tests.

Independent citation and grounding fixtures cover complete URL citations, Responses annotation identity, Gemini chunk/support integrity, declared scalar/UTF-16/UTF-8 units, explicit single/concatenated text layouts, immutable submitted snapshots, Unicode prefix rebasing, overlapping/empty ranges and strict/consented metadata losses. Target events remain withheld through source completion/disposal; malformed layouts, late errors and state/byte limits cannot release success. These tests do not certify real search output or citation accuracy.

PDF and UTF-8 text document fixtures preserve native file/text order, unchanged Base64, CRLF/BOM/NUL, exact byte boundaries and complete tool history. Filename/metadata losses, external provider references, unsupported URL transfer, role/MIME/encoding ambiguity and invalid Unicode retain explicit rejection paths. Opaque document samples do not establish renderability or live document-understanding behavior.

Candidate fixtures retain sparse indices, independent tool/text/filter/length finishes, exact arguments, shared usage and explicitly opted-in stream profiles. Schema/thinking fixtures retain native settings and original constraints through complete request and response snapshots. No test generates target expectations from the conversion implementation or silently enables an unsupported pair/profile.

Ollama, Bedrock Converse and Nova conversions use separate declared native contracts and shared independent goldens. Tests distinguish Claude/AmazonNova dialects, direct/nested layouts, opaque signed histories, native frame attachments and logical target events. Binary frames are never fabricated for converted targets. Unsupported protocols/layouts and unavailable native directions fail before acquisition or HTTP.

Public SDK composition tests use actual OpenAI, Anthropic, Google and AWS adapters to check final endpoint/auth/model/body/events and original native metadata. Configured native paths and credential modes exercise delegation and complete Session binding. Native byte/framing/resource matrices remain in supplier/Infrastructure suites; Conversion owns its mapping, diagnostics and async iterator ownership.

Regressions cover source immutability, declared credential support, missing/foreign response ownership, changed conversion options, original native HTTP errors, typed versus untyped error envelopes, and incomplete/truncated/failed streams. Late native/read/dispose/cancellation failures cannot publish a converted success terminal. Provider-level rejection retains the original LlmUpstreamException/status/payload rather than substituting a permissive conversion error. No real model quality, option effect or universal lossless conversion is claimed.
